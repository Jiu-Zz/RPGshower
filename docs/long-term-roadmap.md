# RPGshower 长期产品路线图

更新日期：2026-09-15

## 长期定位

RPGshower 的长期目标是成为一套面向跑团、小说创作和原创世界观的通用角色工作台。它以结构化角色数据为核心，让用户能够创建、维护、交换和展示角色，并在不绑定单一规则系统的前提下逐步扩展到角色库、世界观管理、跑团辅助和多人协作。

长期建设始终围绕三个核心价值：

1. 通用角色数据：角色资料可校验、可迁移、可交换，不依赖某一个页面或规则系统。
2. 好用的编辑体验：常用操作直接、完整数据可控、错误可恢复。
3. 清晰的角色展示：同一份数据能用于工作台预览、公开分享、打印和其他工具集成。

## 产品阶段

### `0.1.0`（v0）：单角色工作台

当前阶段目标。完成单个角色从导入、编辑、校验、预览到导出的完整闭环。

具体范围和完成标准见 [v0 阶段目标](v0-milestone.md)。

### `0.2.0`（v1）：完整创作与角色资料库

- 创建、复制、删除和归档多个角色。
- 使用浏览器本地存储自动保存，支持刷新恢复。
- 搜索、筛选、排序和批量导入导出角色。
- 使用普通表单编辑标签、档案、资源、属性、装备和技能。
- 增加撤销、恢复示例数据和未保存状态提示。
- 导出适合打印的 PDF、图片或角色卡页面。
- 提供基础主题和只读分享预览。

v1 的完成标志是：用户不必手工编写 JSON，也能在一个设备上长期管理多个完整角色。

### `0.3.0`（v2）：世界观项目与规则扩展

- 将角色组织进小说项目、世界观或跑团战役。
- 管理组织、阵营、地点、事件和世界时间线。
- 建立角色之间以及角色与地点、组织之间的关系。
- 提供人物关系图和时间线可视化。
- 基于 `extensions` 支持规则模板、自定义字段和派生属性。
- 支持 D&D、COC 等规则适配包，同时保持核心角色模型规则无关。
- 提供主题包、数据迁移工具和稳定的角色 JSON Schema。

v2 的完成标志是：RPGshower 能管理一组互相关联的角色和世界设定，并允许替换规则模板。

### `1.0.0`（v3）：云端、协作与开放生态

- 用户账号、云端保存和跨设备同步。
- 所有者、编辑者和只读访客权限。
- 共同编辑、评论、修改记录和版本比较。
- 公开或受限的角色分享链接。
- 主持人视图、玩家视图和隐藏信息。
- 开放 API、插件接口和第三方格式转换。
- 与虚拟桌面、笔记工具和写作软件集成。

v3 的完成标志是：多个用户能可靠地共享和协作维护角色、战役与世界观资料。

## 可选扩展方向

以下能力有价值，但应在核心编辑和数据管理稳定后再立项：

- 跑团会话：快速调整资源、状态效果、骰点与会话日志。
- 媒体管理：头像、立绘、道具参考图、附件和图片画廊。
- 可视化：关系图、世界地图、成长时间线和属性历史。
- AI 辅助：生成角色草稿、补全背景、检查设定冲突、总结经历，以及把自然语言转换为结构化角色数据。

AI 生成内容必须由用户审阅后才写入角色数据；媒体能力需要单独处理存储、隐私和版权问题。

## 长期技术原则

- 核心模型保持规则无关，具体规则进入模板或 `extensions`。
- Schema 是数据契约，TypeScript 类型从 Schema 推导。
- 每次不兼容的数据变化都必须更新版本并提供迁移策略。
- 展示组件只依赖角色对象，不绑定数据来自文件、本地存储还是服务器。
- 先验证单机体验，再引入账号、后端和实时协作。
- 每个阶段都定义可运行的用户闭环，不用未来功能阻塞当前版本发布。

## 暂不承诺的内容

这份路线图记录方向，不表示所有条目都已排期。v1 以后的范围应在前一阶段完成后重新评估，依据实际使用反馈决定优先级。当前开发资源集中在完整 v0。

带有预发布后缀的实施顺序、进入条件和验收标准见 [版本实施计划](version-plan.md)。
